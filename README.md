# Magic: The Gathering System（仮）

フォーマットごとにリーガルなカードだけを検索・表示してデッキを作る、サーバー不要のWebアプリです。
カードデータは [Scryfall API](https://scryfall.com/docs/api) から取得します。

## 機能
- 表示言語の切り替え：上部の丸い国旗（今の言語の国旗。押すと日本語 ⇄ 英語）。選んだ言語はブラウザに記憶（初回はブラウザの言語設定に合わせる）。スマホの対戦画面ではコマンド欄、開始画面では見出しにも国旗がある。カード名は「日本語版で表示」の設定に従う
- フォーマット選択
  - 公式: スタンダード / パイオニア / モダン / レガシー / ヴィンテージ / パウパー / 統率者
  - 非公式: 旧枠モダン / ミドルスクール / オールドスクール（下記参照）
- 選択中フォーマットでリーガルなカードのみ検索結果に表示（`legal:<format>` で絞り込み）
- 日本語カード名での検索（日本語を含むと自動で日本語版を検索）
- 「日本語版で表示」で、英語名で検索した場合もカード名・画像を日本語版で表示（日本語版が存在しないカードは英語版のまま。エクスポートは常に英語名）
- 「初版の絵柄で表示」（既定でオン）で、各カードを最初に印刷された版の絵柄で表示（Scryfall の `prefer:oldest`）。日本語版で表示中は、日本語版の中で最も古い版になります。切り替えるとデッキ内のカード画像も差し替わります
- デッキリストの「絵」ボタンで、カードごとに絵柄（英語版・日本語版の全印刷から）を選べます。選んだ絵柄は一人回しにも反映。「自動に戻す」で上記の設定に戻ります
- Scryfall の検索構文が使えます（例: `t:creature c:r mv<=2`）
- PC の画面配置：左上に絞り込み（フォーマット・色・タイプ・マナ総量・レアリティ）、中央上にカード一覧（並び順・表示の切り替え）、左下にデッキ一覧（クリックで切り替え、ダブルクリックで名前変更）、中央下にデッキの中身（種類ごとに段組み）、右にカードの拡大・マナカーブ・対戦ボタン。画面を開くと、選択中フォーマットのカードが一覧に並ぶ
- 絞り込みは選ぶとすぐに検索し直す（検索欄の文字と組み合わせ可。色は選んだどれかを含むカード）。絞り込みと並び順はブラウザに記憶
- カードをクリックで追加、右クリックで1枚減らす
- 枚数制限チェック（4枚 / 統率者は1枚 / ヴィンテージ・オールドスクールの制限カードは1枚 / 基本土地は無制限）
- フォーマット変更時、使用できないカードや枚数違反を警告表示
- マナカーブ表示、タイプ別グループ表示
- デッキリストをテキストでコピー：「英語でコピー」（`4 Lightning Bolt` 形式、MTG Arena 等に貼り付け可）／「日本語でコピー」（`4 稲妻` 形式。日本語版がないカードは英語名）
- デッキのインポート：「インポート…」にデッキリストを貼り付けると新しいデッキとして読み込む。英語名・日本語名・MTG Arena 形式（`4 Lightning Bolt (M10) 146`）・`4x` 表記に対応。サイドボード（「Sideboard」以降、または MTGO 形式で空行の後ろの15枚以下）は読み込まない
- 複数デッキの管理（新規・名前変更・複製・削除）。フォーマットはデッキごとに保存
- デッキはブラウザ内（localStorage）に自動保存（別のブラウザ・端末とは共有されません）

## 一人回し（play.html）
デッキ作成画面の「一人回し ▶」から開きます。MTGO 風の画面で、ルール処理は基本的に手動です。「自動処理」（下記）がオンなら、読み取れるカードはマナの支払いと効果の解決を自動で行います。

- 先手／後手（またはランダム）を選んで開始 → 7枚ドロー → マリガン（ロンドン・マリガン。キープ後にマリガン回数分を手札からボトムへ）
- フェイズバー：クリックでそのフェイズへ進む。ターン開始時に自動でアンタップ、ドロー・ステップで自動ドロー
- 「次へ」ボタンは今やることを表示し、何も起きないステップ（戦闘開始・ブロック・戦闘終了など）は飛ばす：メイン1は「戦闘へ」（攻撃できるクリーチャーがいなければ「メイン2へ」）、攻撃ステップは「攻撃を確定」／「攻撃しない」で戦闘ダメージの計算 → メイン2まで自動で進む。メイン2からは「ターン終了」（Space でも可）
- メイン1で攻撃できるクリーチャーをクリックすると、攻撃ステップへ進んでそのまま攻撃（{T} の能力を持つクリーチャーは今までどおりタップ）
- 手札：ダブルクリックで唱える（自動処理がオフなら戦場へ。土地は土地の列に並ぶ）
- 戦場：クリックでタップ／アンタップ。右クリックでカウンター、トークン・コピー、移動
- カードの情報：効果テキスト（日本語版があれば日本語）・パワー／タフネス・キーワード能力を Scryfall から取り込む（以前に作ったデッキは、デッキ作成画面を開いたときに自動で補う）。戦場のクリーチャーの右下に今の P/T（ダメージを負うと赤、このターンの修整があると黄色）。マウスを乗せる・スマホで長押しすると効果テキストを表示
- 攻撃ステップ：クリーチャーをクリックでタップして攻撃（もう一度クリックで取り消し、右クリックで警戒としてタップせず攻撃）。戦闘終了で攻撃表示は解除
  - このターンに出たクリーチャー（召喚酔い、「Zz」表示）は攻撃できない。速攻があれば攻撃できる。警戒を持つクリーチャーは自動でタップしない
- 戦闘ダメージ・ステップ：攻撃クリーチャーがいると、ダメージの計算結果を表示（「適用」で反映、「適用しない」で手動処理）。先制攻撃・二段攻撃・トランプル・接死・絆魂・破壊不能を計算し、死亡したクリーチャーは墓地へ。一人回しではブロックされなかったダメージを「与ダメージ」として合計
- P/T の修整：カウンターは +1/+1 カウンター（マイナスなら -1/-1）として P/T に反映。右クリックメニューの「このターン +X/+X…」で一時的な修整（ターン終了で元に戻る）。負ったダメージもターン終了で消える
- 土地のプレイ数をターンごとに表示。2枚目の土地を手札から出すときは確認
- クリーンアップ（「ターン終了」含む）で手札が8枚以上なら、7枚になるまで捨てるカードを選択（「捨てずに続ける」でスキップ可）
- どのカードも右クリックメニューかドラッグで、手札・戦場・墓地・追放・ライブラリーの上／下へ移動
- ライブラリー：クリックで1枚ドロー、右クリックで X枚ドロー・シャッフル・上からX枚を見る・探す・切削
- 墓地・追放：クリックで一覧
- ライフ（統率者デッキは40から開始）、トークン生成、行動ログ
- 勝敗の表示：ライフが0以下、空のライブラリーから引こうとした、コマンド欄の「投了」で「敗北」を表示（ネット対戦では相手に「勝利」を表示）。「元に戻す」やライフを戻すと取り消される
- 左の列に現在のフェイズの案内文を表示
- 戦場の背景を神殿（既定）・川・沼地・マグマ・森の絵から選択（上部の丸いボタン。ブラウザに記憶）。デッキ作成画面の検索結果はグレーの岩肌で固定
- アバター：開始画面で18種類から選ぶ（自分のアバターをクリックでも切り替え）。ネット対戦では相手にも表示
- フェイズ・ライフ・手札・ライブラリー・墓地・追放・元に戻すにはアイコン付き（`img/` の画像）
- 効果音：ドロー・タップ・呪文・攻撃・ライフ減少・フェイズ／ターンの移り変わりなどで鳴る。戦場に出したときはカードの種類（クリーチャー・アーティファクト・エンチャント）で、土地は出せるマナの色（単色・2色。無色や3色以上は共通の音）で変わる（`sounds/` の WAV。コマンド欄の「効果音」でオン・オフ、ブラウザに記憶）
- ショートカット：Space＝次のフェイズ、Enter＝ターン終了、D＝1枚引く、Ctrl+Z＝元に戻す
- 対戦中の状態はタブを閉じるまで保持（リロードしても続きから）

## 自動処理（play.html の手助け）
コマンド欄の「自動処理：オン／オフ」で切り替えます（既定はオン、ブラウザに記憶）。英語の効果テキスト（Oracle）を読み取って処理します。旧枠モダン（〜スカージ初出）のカードでよく見る書式を中心に対応しています。

- 唱える：手札をダブルクリック（右クリック／スマホはタップのメニューの「唱える（自動でマナを払う）」）。アンタップ状態の土地と「{T}: Add …」のマナ能力から、払える組み合わせを自動で選んでタップする（多色土地・マナ・クリーチャーはなるべく残す）。X のある呪文は X を聞く
  - インスタント・瞬速以外は自分のメイン・フェイズのみ。マナが足りないときや手で処理したいときは「マナを払わずに唱える」か「戦場へ」
  - 呪文は解決後に墓地へ。パーマネントは戦場へ
- 対象：画面上部の案内に従い、光っているカード（自分・相手の戦場）か「あなた」「相手」のボタンを選ぶ（Esc でキャンセル）。被覆・呪禁は対象にできない
- 読み取れる効果（インスタント・ソーサリーの効果と、パーマネントの「戦場に出たとき」の効果）
  - ダメージ：「N damage to any target / target creature / target player / each creature / each opponent」など（X も可）
  - 破壊・追放・手札に戻す・タップ・アンタップ（「黒でない」「アーティファクトかエンチャント」などの条件付き）、「すべてのクリーチャーを破壊」など
  - ドロー、ライフを得る・失う、手札を捨てさせる（相手が選ぶ）
  - 「このターン +N/+N（とキーワード）」、+1/+1 カウンター、トークン生成、基本土地を探して戦場／手札へ
- ほかにも自動で扱うもの
  - 「タップ状態で戦場に出る」土地・パーマネント
  - ロード：「Creatures you control get +1/+1」「Other Goblins get +1/+1」などを P/T とキーワードに反映（自分の戦場のクリーチャーのみ）
  - 状況起因処理：致死ダメージを負った・タフネスが0以下のクリーチャーは墓地へ
- 読み取れない文（打ち消し・起動型能力・オーラ・装備・モードを選ぶ呪文など）は、ログに「手動で処理してください」と出るので今までどおり手で処理する
- 相手（ネット対戦）のカードへの効果は相手の画面にも反映される（送った後は「元に戻す」で戻せない）

## ルール対戦（duel.html）
デッキ作成画面の「ルール対戦 ▶」から開きます。カードの効果テキスト（英語の Oracle）を読み取り、ルールどおりに自動で進む対戦です。一人回し・手動のネット対戦（play.html）とは別の画面です。

- 相手：**CPU**（相手のデッキを選ぶ。既定の「ランダム」は、旧枠モダンのカードのうち自動で処理できるものから、毎回2色のデッキを組む：基本土地24枚・クリーチャー20枚（軽いものを多め）・ほかの呪文16枚。始めたときに色を表示し、CPU の名前にマウスを乗せても見られる）／**練習相手**（何もしない）／**ネット対戦**（部屋を作る・部屋に入る。部屋を作った側の画面でゲームを処理し、入った側には隠す情報を除いた状態だけを送る）
- 開始画面に、選んだデッキのうち自動で処理できるカードの枚数と、読み取れない文の一覧を表示
- 操作
  - 手札のクリックで土地をプレイ・呪文を唱える（マナは自動で支払う。X は値を聞く）。対象は光っているカード・スタックの呪文・プレイヤーのボタンから選ぶ（Esc で取り消し）
  - 戦場のパーマネントのクリックで起動型能力（土地・マナ能力を手で起動してマナ・プールに出すこともできる）。右クリック／長押しでメニュー（サイクリング・フラッシュバックなど）
  - 「パス」で優先権を渡す。両者がパスするとスタックの一番上が解決する／次のステップへ進む。「ターン終了まで」で、相手が何かするまで自動でパス
  - 唱えた呪文・起動した能力・誘発型能力は画面の中央に大きく表示する（相手のものは長め。クリックで閉じる）。CPU はこの表示が終わるまで次の行動を待つ。ダメージ・破壊・打ち消しなどの主な出来事は画面の上に数秒ずつ表示する
  - 土地：同じ土地はまとめて「×5」のように表示（タップ済みは別）。プレイヤーの欄に「使えるマナ」を色ごとに表示。手札の呪文にカーソルを乗せると、自動で支払うときにタップされる土地が光る。戦場の土地をクリックしてもマナは出ない（手で出すときは右クリック）
  - 何もできないステップは自動でパスする（自分のメイン・フェイズ、相手の呪文に対応できるとき、戦闘・相手の終了ステップでインスタントを使えるときは止まる）。「すべてのステップで止まる」で毎回止まる
- ルールの処理（engine.js）
  - ターンの進行（各ステップ）、優先権、スタック（呪文・起動型能力・誘発型能力）、対象の適正（不適正なら打ち消される）
  - 打ち消し（「〜を支払わないかぎり」も）、再生、破壊不能、被覆・呪禁・プロテクション
  - 戦闘：攻撃・ブロックの制限（召喚酔い・防衛・飛行／到達・威迫・畏怖・威嚇・シャドー・〜渡り・「ブロックできない／されない」）、先制攻撃・二段攻撃・トランプル・接死・絆魂、霧
  - 状況起因処理（ライフ0・空のライブラリーから引く・致死ダメージ・タフネス0・オーラの外れ・レジェンド・ルール）、手札の上限、マリガン（ロンドン）
  - 継続的効果：ロード、オーラ・装備品（装備）、「〜をコントロールしているかぎり」、このターンの修整、+1/+1・-1/-1カウンター
  - キーワード：エコー、サイクリング、フラッシュバック、瞬速、速攻、警戒 など
  - 誘発型能力：戦場に出たとき・死亡したとき・アップキープ・終了ステップ・攻撃したとき・ブロックしたとき・プレイヤーに戦闘ダメージを与えたとき
- 読み取れる効果（cardtext.js）：ダメージ・破壊・追放・バウンス・タップ／アンタップ・修整・カウンター（+1/+1・-1/-1・名前のあるもの）・トークン・ドロー・ライフ・捨てる（選ぶ・無作為・公開して選ぶ）・切削・サーチ（土地・クリーチャーなど）・墓地からの回収・打ち消し・再生・軽減（次のNダメージ・「〜の発生源」）・マナ（マナ能力・儀式・「〜につき」）・生け贄・占術・上から見て選ぶ など
  - 「〜の数に等しい」「〜1つにつき」の数、モードを選ぶ呪文（Choose one）、キッカー、追加のコスト、スレッショルド、「that player / that creature」を指す誘発（死亡したとき・戦場に出たとき・捨てたとき・引いたとき・呪文を唱えたとき など）
- 読み取れないカードの文は、ログとカードの詳細に「手動で処理」と出る（カードに赤い「手」の印）。cards.js にカードごとの定義を書くと上書きできる
- CPU（ai.js）：マリガン、土地・呪文（重いもの優先）、オーラ・装備のつけ先、攻撃・ブロック（相打ち以上・チャンプ・ブロック）、打ち消し、再生、戦闘中の修整・霧、相手の終了ステップのインスタント・ピンガー
- 再読み込みしても続きから（ネット対戦も同じ部屋に戻る）
- 以前に作ったデッキは、デッキ作成画面を一度開くとマナ・コストと色が補われる
- テスト：`node tests/engine.test.js`（ルールの個別のテスト、実際のカードの Oracle テキストでのテスト、CPU 同士の対戦。`GAMES=1000` で旧枠モダンのランダムなデッキの対戦の数を変えられる）

### 旧枠モダンのカード一覧と対応状況
- `data/oldframe-modern.json`：旧枠モダン（モダンでリーガルかつ第8版より前に印刷されたことがあるカード）の全カード。`node tools/fetch-oldframe-modern.js` で Scryfall から取り直せる
- [docs/coverage.md](docs/coverage.md)：自動で処理できる割合と、読み取れない文があるカードの一覧（`node tools/coverage.js --write` で更新）。読み取れないカードは cards.js にカードごとの定義を書くか、cardtext.js・engine.js に書式を足す

## ネット対戦（play.html）
デッキ作成画面の「一人回し ▶」から開き、開始画面で「ネット対戦」を選びます。ルール処理は一人回しと同じく手動です。

1. 片方が「部屋を作る」で開始 → 画面上部とログに表示される6文字の**部屋コード**を相手に伝える
2. もう片方は「部屋に入る」に部屋コードを入力して開始
3. 先手・後手は部屋を作った人の選択（ランダム／先手／後手、最初はランダム）で決まり、入った側は自動で逆になる。両者キープ後、先手から始まる
   - 部屋を作ると、相手が入るまで戦場の上段に部屋コードを大きく表示（「共有・コピー」でLINEなどに送れる）
   - 対戦中は、今より前のフェイズには戻れない（ターンの終わりを越えて相手に渡ってしまうのを防ぐため）
4. インスタントを唱えられるステップ（アップキープ〜終了。アンタップ・クリーンアップ以外）を「次へ」「ターン終了」で終えるときは、相手が「OK」を押すまで進まない
   - 相手側には依頼が表示され、「OK」（Space / Enter でも可）で進めてよい、「対応する」で待ってもらう（インスタントを唱えるなど。終わったら「OK」）
   - 「このステップは次から自動でOK」にチェックすると、そのステップは以後自動で OK（コマンド欄の「自動OKをすべて解除」で戻す）
   - 通信が切れている間は承認なしで進む
5. 「ターン終了」で相手のターンへ。相手のターン中もカードの移動・タップ・ライフ変更などはできる
6. ブロック：相手が攻撃してきたら、自分のクリーチャー → 相手の攻撃クリーチャーの順にクリックしてブロック（ブロックしたクリーチャーをもう一度クリックで取り消し、複数でのブロックも可）。飛行は飛行か到達でしかブロックできない。威迫などほかの制限は計算結果に注意として出る
   - 攻撃側が戦闘ダメージを「適用」すると、守る側のライフ・クリーチャーにも反映される（適用後は「元に戻す」で戻せない）

- 画面の上半分が相手の戦場、左の列の上が相手のライフ・ライブラリー枚数・手札枚数・墓地・追放（墓地・追放はクリックで一覧）
- 相手に見えるのは MTGO と同じ範囲：戦場・墓地・追放・ライフ・ライブラリー枚数・手札枚数・ログ。手札の中身とライブラリーの順番は見えない
- ログに相手の行動とチャットもまとめて表示。チャットはログの下の入力欄から
- 再読み込みしても同じ部屋に再接続する。通信が止まったときは「自分のターンを始める」で手動で進められる
- ターンを渡した・受け取った後は「元に戻す」で戻れない
- 接続の仲介に [PeerJS](https://peerjs.com/) の無料公開サーバーを使い、つながった後はブラウザ同士で直接通信する。会社・学校などのネットワークではつながらないことがある
- 動作確認用に、URL の末尾に `?local=1` を付けると同じPCの2つのタブ同士で対戦できる（通信サーバー不要）

## スマホ
幅の狭い画面（スマホ）では、自動でスマホ用の配置に切り替わります。PC ではウィンドウいっぱいに表示し、列の幅・カード・文字の大きさを画面の幅と高さに合わせて変えます（16:9・16:10・21:9、1366×768 などのノートPCの画面にも対応。とても小さいウィンドウでは 980×620 を下限にスクロール）。ネット対戦は PC とスマホの組み合わせでも遊べます。

- カードを長押しすると、画面いっぱいに拡大表示（どこかをタップで閉じる）
- デッキ作成：上の「カード検索」「デッキ」で切り替え。検索結果をタップでデッキに追加、デッキの「−」で減らす。検索結果やデッキのカード名を長押しで拡大表示（「1枚追加」「1枚減らす」も可）
- 一人回し・対戦（縦向きがおすすめ）：
  - 上からライフ・山札 → 相手の戦場 → 自分の戦場 → 手札 → 今のフェイズのボタンと「次へ」「ターン終了」
  - 今のフェイズのボタン（例：「メイン1 ▼」）を押すと、フェイズの一覧から選んで進められる
  - 手札のカードをタップ：拡大画像とメニュー（「戦場へ」など）
  - 戦場のカード：タップでタップ／アンタップ、長押しで拡大表示。「操作メニュー」から攻撃・カウンター・移動
  - 相手のカードをタップ・長押し：拡大表示
  - ライブラリー：タップで1枚引く、長押しでメニュー
  - 画面下の「ログ・チャット」「コマンド」で各欄を開く。相手の行動やチャットが届くと「ログ・チャット」に ● が付く
- 横向きでは左の列にライフ・山札とターンのボタン、右に戦場と手札

## 非公式フォーマットの判定ルール
Scryfall に判定がないため、`app.js` 冒頭の定義で判定しています。ルールは主催者や時期で異なるので、必要に応じて編集してください。

| フォーマット | 使用可能カード | 禁止・制限 |
|---|---|---|
| 旧枠モダン | モダンリーガルかつ第8版より前（〜スカージ）に印刷されたことがあるカード | モダンに準拠 |
| ミドルスクール | 第4版〜第7版の期間（1995/4〜2003/7）に印刷されたカード＋一部プロモ。銀枠・アンティ等はヴィンテージ非リーガルとして除外 | MTG Wiki 記載の禁止25種 |
| オールドスクール | Eternal Central ルール: アルファ〜リバイズド、アラビアンナイト、アンティキティー、レジェンド、ザ・ダーク、フォールン・エンパイア＋HarperPrism プロモ3種（再録版も可） | アンティカード禁止、EC の制限カード（各1枚） |

- 日本語名で非公式フォーマットを検索する場合、日本語名の候補を古い順に最大100件取得してから判定するため、候補が多いと漏れることがあります。英語名か条件追加で絞り込んでください。

## 無料で公開する（GitHub Pages）
1. GitHub にリポジトリを作成し、このフォルダの中身を push
2. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

Cloudflare Pages や Netlify でも、フォルダをそのままアップロードするだけで公開できます（ビルド不要）。
